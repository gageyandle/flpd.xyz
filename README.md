# flpd.xyz
My personal website for hosting my Github/LinkedIn links and other things I have made.

## Repository Structure

The **root** of this repo is the live website (what gets served at flpd.xyz):

```
/
├── index.html          ← main page
├── contact.html
├── portfolio.html
├── skills.html
├── gallery.html
├── style.css
├── images/             ← site images (bg, favicon, gallery photos)
├── misc/               ← font & audio assets
├── scripts/            ← JavaScript
├── old/                ← archived old page versions
└── testfiles-ignore/   ← local test files (not served)
```
